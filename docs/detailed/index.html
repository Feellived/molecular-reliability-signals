요약세 줄로 줄이면

ADMET 예측 모델은 평균 정확도로 평가받는다. 그런데 신약 탐색 현장에서 필요한 것은 눈앞의 분자 하나에 대한 예측을 실험으로 검증할 가치가 있는지다. 지금 쓰이는 신뢰성 지표 — 적용가능도메인, 컨포멀 불확실성, 모델 불일치 — 는 모두 모델과 학습 데이터를 들여다본다.

이 연구는 입력을 들여다보는 신호를 제안하고 검증한다. 같은 화합물도 데이터베이스마다 다른 형태로 등록된다. 중성형과 이온형, 서로 다른 호변이성질체, 입체 표기가 있는 것과 없는 것이 모두 같은 약이다. 그 형태를 바꿔 넣었을 때 예측이 크게 달라진다면, 애초에 어느 형태를 넣었느냐가 답을 가른다는 뜻이다.

입력 상태 민감성은 CYP 억제 예측에서 기존 신호에 더해 위험 선별을 개선한다. 범용 신뢰성 지표로 쓰기에는 근거가 부족하다.

검증 결과

  • 사전 지정한 1차 가설이 지지된다. 계획서가 정한 기준 모형(적용가능도메인 + 컨포멀)에 B축을 더하면 정규화 AURC가 평균 0.0286 개선되고, 골격 군집 부트스트랩 95퍼센트 신뢰구간 [+0.0031, +0.0561]이 0을 배제한다. 22종 중 14종에서 개선됐다.
  • 2차 가설은 지지되지 않는다. 표현 불안정성 A를 더한 효과는 +0.0003으로 사실상 0이고 신뢰구간이 0을 포함한다.
  • 효과가 CYP 물성에 집중된다. CYP 6종 평균 +0.080(6종 모두 개선), 그 외 16종 평균 +0.009(8/16). 다중 비교를 BH로 보정한 뒤 개별 물성 수준에서 유의한 것은 CYP 억제 3종뿐이다.
  • 이 집중이 새 데이터에서 재현됐다. 22종에 쓰이지 않은 CYP1A2·CYP2C19에서, 구성과 판정 기준을 커밋한 뒤 한 번만 평가해 +0.054와 +0.089를 얻었고 두 물성 모두 신뢰구간이 0을 배제했다.
  • CYP 밖으로 확장되는지는 확인하지 못했다. 같은 화합물을 같은 조건으로 측정한 Biogen 데이터에서 CYP 관련 물성이 대조 물성보다 낫지 않았다.
  • CYP에서 잘 되는 이유는 설명하지 못했다. 사전 등록한 설명 가설(물성의 이온화 민감도)은 기각됐다.

이 문서는 간결판 보고서의 상세판이다. 방법의 세부 설정, 물성 22종 각각의 수치, 실패한 시도의 내역, 사전 등록 문서의 판정 기준을 모두 싣는다.

1문제

1.1 평균 정확도와 개별 신뢰의 간극

가상 탐색에서 모델은 수만 개 분자에 점수를 매긴다. 이때 “이 모델의 R²가 0.7이다”라는 정보로는 지금 눈앞의 분자 하나를 실험으로 검증할지 말지 정할 수 없다. 그 판단에는 예측별 신뢰도가 필요하다.

1.2 기존 신호는 모두 모델 쪽에서 나온다

신호무엇을 보나산출 원천
적용가능도메인이 분자가 학습 데이터와 얼마나 닮았나학습 데이터 분포
컨포멀 불확실성모델이 내놓는 예측 구간이 얼마나 넓은가모델 출력
모델 불일치서로 다른 모델이 같은 분자에 다른 답을 내는가모델 출력

세 신호는 서로 상당 부분 겹친다고 보고되어 왔다. QUAD(2026)는 세 신호를 단일 점수로 통합했을 때 가장 좋은 단일 신호보다 오히려 나빴다고 결론지었다(무작위 분할에서 앙상블 불확실성 단독 0.366 대 통합 0.303). 따라서 모델 쪽 신호를 더 많이 결합하는 방향은 유망해 보이지 않는다.

1.3 입력 쪽에 남은 미탐색 영역

화학 데이터베이스는 같은 약을 여러 형태로 등록한다. 어느 형태가 저장되는지는 등록 파이프라인의 선택에 달려 있고, 모델을 쓰는 사람은 그 선택을 통제하지 못한다. 주요 공개 데이터베이스들의 표준화 파이프라인이 서로 다른 결과를 낸다는 것은 이미 보고된 사실이다(canSAR 2022).

그 형태를 바꿨을 때 예측이 크게 달라진다면, 애초에 어느 형태를 넣었느냐가 답을 가른다. 이것이 이 연구가 제안하는 신호다.

1.4 기여

새로운 예측 모델도, 새로운 불확실성 이론도, 신호 통합 방법도 아니다. 기여는 두 가지다. 첫째, 입력 쪽에서 산출되는 신호를 분자 단위로 정량화했다. 둘째, 기존 적용가능도메인·컨포멀 기준선 대비 추가 가치를 골격 기반 분할 조건에서 사전 지정 가설로 검정하고, 그 결과가 어느 물성군에 한정되는지를 독립 데이터로 확인했다.

2관련 연구

2.1 모델 기반 신호의 통합 시도

QUAD(2026)는 앙상블 불확실성, 모델 불일치, 적용가능도메인 위험을 분자 단위 신뢰도 점수로 통합하는 사후 프레임워크를 제안했다. Random Forest와 ECFP4 지문으로 두 생물활성 벤치마크를 무작위 분할과 Bemis-Murcko 골격 분할 양쪽에서 평가하고 구성 요소별 제거 실험도 수행했다. 결과는 통합의 유효성을 지지하지 않았다. 골격 외삽 조건에서는 한 데이터셋의 통합 점수 상관계수가 0.071까지 떨어졌다. 저자들은 효과가 데이터셋 특성에 강하게 의존한다고 결론지었다.

2.2 적용가능도메인과 컨포멀의 중복성

ACS Omega(2026)는 k-최근접 이웃 기반 적용가능도메인 지표가 컨포멀 불확실성 추정치를 언제 신뢰하기 어려운지 구분해 준다는 것을 시간 분할과 군집 분할에서 보였다. Chemical Research in Toxicology(2026)는 컨포멀 예측을 100개 이상의 QSAR 모델에 보정 계층으로 적용하고, 컨포멀 효율 지표(예측 구간 폭, 단일 라벨 비율)가 적용가능도메인 지표와 강하게 상관한다고 보고했다. 저자들은 컨포멀 예측이 적용가능도메인 휴리스틱이 근사하던 관계를 통계적으로 정식화한 것이라고 해석했다.

이 두 결과는 양방향으로 작용한다. 기준선을 정의하는 동시에, 두 신호가 상당 부분 같은 정보를 담고 있다면 산출 원천이 다른 제3의 신호가 갖는 가치가 그만큼 커진다.

2.3 표현 등가 변동을 이용한 신뢰도 추정

등가 SMILES 표기 간 예측 변동을 신뢰도로 쓰는 접근은 Maxsmi(2021)에서 제시됐다. 무작위화 SMILES를 학습 증강에 쓰면서, 추론 시점에 여러 등가 표기를 넣어 얻은 예측 분산을 신뢰도 추정에 활용했다. 따라서 이 연구의 표현 불안정성 A는 새로운 개념이 아니며, 그래서 2차 가설로 두었다.

다만 Maxsmi는 증강 학습이 표현 불안정성을 얼마나 줄이는지, 증강 이후에도 잔존하는 불안정성이 오차 신호로 기능하는지는 검증하지 않았다.

2.4 화합물 등록과 표준화

canSAR 등록 파이프라인(2022)은 구조 검사, 표준화, 정준 호변이성질체 생성, 염 제거, 추상 구조 생성의 다섯 단계로 화합물 계층을 구성한다. 이 계층 구조가 B를 세 축으로 분리한 근거다. Genentech의 구조 정규화 연구(2012)는 외부 유입 화합물의 동일성 판정에 입체화학 불확실성과 호변이성질체를 함께 처리해야 한다고 기술했다. 구조 큐레이션 연구(2010)는 한 대규모 데이터셋에서 약 10퍼센트의 화합물이 혼합물이거나 염 형태여서 계산 전 처리가 필요하다고 보고했다.

이들은 표준화를 올바르게 수행하는 방법을 다룬다. 표준화 선택에 대한 분자별 민감도를 측정하거나 그것을 신뢰성 신호로 쓴 연구는 아니다. 호변이성질체·양성자화 상태의 다중성을 다룬 연구들도 주로 비율 예측이거나, 도킹에서 상태 열거가 농축률을 높이는지 검토한 것이다(2009). 상태 열거를 예측 성능 개선 수단으로 다루었지, 상태에 따른 예측 변동을 불확실성 신호로 다루지 않았다.

2.5 연구 공백

새 신뢰성 신호를 제안하고 보류 실험으로 기존 신호 대비 우월성을 보이는 형식은 확립되어 있다. AUINet(2026)은 원자 단위 불확실성이 분자 단위 불확실성보다 나은 오차 신호임을 보였다. 이 연구도 같은 검증 형식을 따르되, AUINet의 신호가 몬테카를로 드롭아웃 기반으로 여전히 모델 쪽에서 산출된다는 점에서 구분된다.

확인한 범위에서, 호변이성질체·양성자화·염 형태·입체 표기의 변동을 분자 단위 신뢰성 신호로 정량화하고 기존 기준선 대비 추가 가치를 측정한 연구는 발견되지 않았다. 검색은 Europe PMC, CrossRef, arXiv, Semantic Scholar를 대상으로 했다.

3.2 계층적 분산 분해

한 분자에 대해 여러 화학적 상태를 만들고, 각 상태 안에서 다시 여러 등가 SMILES를 만든다. 상태와 표기의 이중 중첩 구조에서 두 축은 이렇게 정의된다.

A² = 상태 내부에서 등가 SMILES 사이의 예측 분산을, 상태들에 대해 평균 B² = 각 상태의 평균 예측값을 먼저 구한 뒤, 그 상태 평균값들 사이의 분산

변형 개수가 상태 간에 균형을 이루면 전체 분산은 A² + B²로 정확히 분해된다. 실제로는 분자마다 생성 가능한 상태 수가 달라 이 조건이 항상 성립하지는 않는다. 주 분석은 이 정식 정의 대신 축별 백분위의 최댓값을 쓰는 근사를 사용하고(4.8절), 정식 정의는 민감도 분석으로 함께 보고한다.

3.3 연구 질문

  • RQ1 (분해와 특성화) — 등가 SMILES 변형과 상태 변형에 대해 ADMET 예측은 어느 정도 변동하며, 그 크기는 물성 종류·모델의 표현 방식·학습 골격으로부터의 거리에 따라 어떻게 달라지는가.
  • RQ2 (비중복성) — A와 B는 적용가능도메인 및 컨포멀과 어느 정도 중복되는가. 이 질문은 정답 라벨 없이 답할 수 있다.
  • RQ3 (추가 가치) — 기존 신호에 A와 B를 더했을 때 골격 기반 시험 집합에서 오차 탐지와 선택적 예측이 개선되는가.

3.4 사전 지정 가설

RQ3이 주 분석이며, 두 가설을 데이터 관찰 전에 지정했다.

1차 가설. 적용가능도메인과 표본 적응형 컨포멀만으로 구성한 기준 모형에 입력 상태 민감성 B를 추가하면, 골격 기반 시험 집합의 정규화 AURC가 감소한다.

2차 가설. 동일 기준 모형에 표현 불안정성 A를 추가하면 정규화 AURC가 감소한다. SMILES 언어 모델이 확보된 물성에 한정해 검정한다.

두 가설을 분리한 이유는 세 가지다. A는 SMILES를 직접 읽는 모델이 있어야만 0이 아닌 값을 갖는 성립 조건을 가진다. A는 선행 연구에서 이미 신뢰도 추정에 쓰인 개념이므로 이 연구의 고유한 주장은 B에 있다. 둘을 묶어 검정하면 A쪽의 실행상 문제가 B에 대한 결론까지 무효화한다.

4방법

4.1 데이터

Therapeutics Data Commons의 ADMET Benchmark Group을 쓴다. 회귀 9종과 분류 13종, 합계 22종이며 표준 골격 기반 분할이 함께 제공된다. 22종 전체를 같은 깊이로 분석한다. 당초 일부 물성만 심층 분석하는 두 층 설계였으나 2026년 8월 20일 철회했다. 물성별 편차 자체가 이 연구의 관심사이고, 대상을 좁히면 신호가 어떤 물성에서 작동하고 어떤 물성에서 작동하지 않는지를 규명할 수 없기 때문이다. 물성 수가 늘어남에 따른 다중 비교는 5.3절 절차로 통제한다.

4.2 물성별 변형 허용성

모든 변형이 모든 물성에 유의미하지는 않다. logD처럼 정의에 pH가 들어간 물성에서는 양성자화 변형이 본질적이다. 반면 여러 출처를 통합하면서 측정 조건이 보존되지 않은 물성에서는 같은 변형이 잡음이다.

4.4 변형 가능성 사전 선별

4.6 기준선 신뢰성 신호

넘어서야 할 기준선은 적용가능도메인과 표본 적응형 컨포멀 둘이다.

  • 적용가능도메인 2종 — Morgan 지문 공간의 k-최근접 이웃 유사도, 같은 공간의 국소 밀도. 두 정의를 모두 지문 공간에서 산출한 것은 의도적이다. 학습된 임베딩 거리를 쓰면 그 임베딩을 제공하는 모델이 사실상 ChemBERTa가 되는데, A축과 모델 불일치가 이미 그 모델에 의존한다. 기준선까지 같은 구성 요소에 묶으면 해당 모델을 확보하지 못했을 때 비교 대상 자체가 절반 사라진다.
  • 컨포멀 — 회귀는 앙상블 분산으로 조정한 적응형 구간, 분류는 APS 비적합도 점수와 예측 집합 크기.
  • 모델 불일치 — 지문 모델과 ChemBERTa처럼 분자 표현 방식이 다른 모델 사이의 예측 차이. 같은 특징을 쓰는 두 트리 모델의 차이는 앙상블 분산과 실질적으로 같은 정보라 별도 신호로 보지 않는다. 계획서가 정한 기준 모형에는 포함되지 않지만, 참고 비교로 항상 함께 보고한다.

4.7 데이터 분할 규율

부모 분자 확정 → 중복 제거 → 골격 기준 분할 → 그 다음에 변형 생성

세 번째 조건이 핵심이다. 변형을 먼저 만들면 같은 화합물의 다른 표기가 학습과 시험에 나뉘어 배정되어 정보 누출이 생긴다. 변형은 원본 행의 분할을 그대로 물려받는다.

분할은 네 역할로 나눈다. 학습, 컨포멀 보정(예측 구간 폭 결정), 메타 보정(신호 결합 규칙과 임계값 결정), 최종 시험(골격 기반, 단 한 번만 사용). 표본이 작은 물성에서는 학습·검증 영역 안에서 골격 그룹 단위 교차적합을 하고 폴드 외 예측으로 메타 모델을 학습한다. 결합 규칙은 최종 시험 집합에 한 번만 적용한다.

4.8 신호 산출과 정규화

물성마다 단위와 분포가 달라 예측값을 그대로 비교할 수 없다. 회귀는 보정 집합 라벨의 사분위 범위로 나누어 표준화하고, 분류는 확률을 양 끝에서 절단한 뒤 로짓으로 변환한다.

B1과 B3는 변형의 개수와 강도가 서로 달라 원값을 직접 비교하거나 최댓값을 취할 수 없다. 보정 집합에서 각 축의 분포를 구해 백분위로 변환한 뒤, 그 백분위의 최댓값을 통합 B로 쓴다. 백분위 기준과 모든 임계값은 시험 집합이 아니라 보정 집합에서 고정한다.

5평가 프로토콜

5.1 지표

정규화 AURC가 판정 지표다. 신뢰도 순서대로 예측을 받아들이며 누적 오차를 재고, 무작위 보류를 1, 이상적 보류(오라클)를 0으로 정규화한다. 낮을수록 좋다. 기준선 없이 “보류 비율을 높이니 잔여 오차가 줄었다”는 관찰은 매우 약한 신호에서도 거의 항상 성립하므로 그 자체로는 근거가 되지 못한다.

오차 탐지 AUPRC를 함께 보고한다. 큰 오차 사례가 소수라 클래스 불균형에 강건한 지표가 적절하다. 큰 오차의 정의는 분류에서는 오분류, 회귀에서는 절대 오차 상위 20퍼센트다.

5.2 제거 실험

신호를 순차적으로 더하며 한계 기여도를 잰다. 각 구성은 물성 안 백분위 신호를 메타 분할에서 오차 순위에 대해 적합한 Ridge(alpha 1.0)로 결합하고, 시험 분할에서 정규화 AURC를 계산한다.

  1. 적용가능도메인 단독
  2. 적용가능도메인 + 컨포멀 — 계획서가 정한 기준 모형
  3. 기준 모형 + 모델 불일치
  4. 기준 모형 + A — 2차 가설
  5. 기준 모형 + B — 1차 가설
  6. 전체

5.3 통계적 추론

  • p값 중심 서술을 지양하고 물성별 효과 크기와 신뢰구간을 보고한다.
  • 신뢰구간은 골격 군집 단위 부트스트랩으로 산출한다. 같은 골격의 분자들은 독립이 아니기 때문이다. 복원 추출 2,000회, 시드 20260926, 재표집 시 결합 규칙은 다시 적합하지 않는다.
  • 다중 비교는 Benjamini-Hochberg로 통제하되, 사전 지정한 1차 가설에는 적용하지 않는다.

골격 단위 재표집은 분자 단위보다 구간을 넓힌다. 실제로 1차 가설의 신뢰구간은 분자 단위 [+0.0086, +0.0532]에서 골격 단위 [+0.0031, +0.0561]로 넓어졌다. 더 보수적인 쪽을 판정에 쓴다.

물성 6종을 싣는다. B축이 잘 작동하는 CYP 둘과 거의 작동하지 않는 넷을 함께 둔다. 이 도구는 신호가 언제 작동하지 않는지도 보여주려고 만들었다. 세 축을 단일 점수로 합치지 않는 것은 1.2절에서 QUAD의 결과를 인용한 것과 같은 이유다.

14주장의 범위

주장할 수 있는 것

  • 사전 지정한 1차 가설이 지지된다. 계획서가 정한 기준 모형 대비 B축 추가가 위험 선별을 개선하고, 골격 군집 신뢰구간이 0을 배제한다.
  • 이 신호는 기존 신호와 원천이 다르다. 순위 상관이 거의 0이고, 골격 거리와 반대 방향으로 움직이며, 기존 신호를 통제해도 정보가 남는다.
  • CYP 억제 물성에서 유효하며 독립 데이터 두 종에서 재현됐다. 구성을 결과 관찰 전에 고정했고 평가는 한 번만 했다. 분자 복잡도 기술자를 통제한 뒤에도 유지된다.
  • 안전 인증에 강하다. 믿을 만하다고 고른 20퍼센트의 오류율이 기준의 0.46배에서 0.39배로 낮아진다.

주장할 수 없는 것

  • 범용 신뢰성 지표. CYP 밖에서는 효과를 확인하지 못했고, 그 영역에서는 분자 크기 세 개만 넣은 기준이 B축보다 낫다.
  • 기존 신호를 대체한다. 모델 불일치가 2.5배 강하다. B축은 대체재가 아니라 보완재다.
  • CYP 관련 물성 전반으로의 확장. Biogen에서 확인하지 못했다.
  • CYP에서 잘 되는 이유. 사전 등록한 설명 가설이 기각됐고 대안 가설은 아직 없다.

15한계

  1. 효과 크기가 작다. 기준 대비 5퍼센트 수준이다. 다만 분야 전체가 이 수준이다. 가장 강한 기존 신호도 무작위와 완벽 사이의 30퍼센트밖에 가지 못한다.
  2. 물성 22종은 효과 크기 +0.01을 가려내기에 부족하다. CYP 밖 16종의 신뢰구간이 [−0.006, +0.028]로 넓다. “효과가 없다”가 아니라 “있는지 없는지 이 표본으로는 모른다”가 맞는 서술이다.
  3. 언어 모델이 ChemBERTa 하나뿐이다. A축은 원리상 문자열 모델에서만 나오므로 구조 기반 모델로는 검증할 수 없다. 2차 가설의 기각은 “A축이 쓸모없다”가 아니라 “이 모델에서는 쓸모가 없었다”로 읽어야 한다.
  4. CYP 집중이 사후 발견이다. 새 데이터 두 종으로 재현했지만, 애초에 이 패턴은 결과를 본 뒤에 찾았다. 재현은 사후 발견을 확증으로 바꾸지 않고 신뢰도만 높인다.
  5. 측정 조건 분류에 민감하다. 허용성 표의 판정 하나로 결론이 뒤집힌 전례가 있다(12절). 이 분류는 사람의 문헌 판독에 의존한다.
  6. Biogen 확장의 검정력이 부족했다. 시험 분자가 217~308개였다. 이 결과로 확장 가능성을 배제할 수는 없다.

  • 사전기록 1 — “ρ > 0이고 p < 0.05이면 지지. ρ > 0이나 p ≥ 0.05이면 검정력 부족으로 보고. ρ ≤ 0이면 기각.”

세 문서 모두 같은 약속으로 끝난다. 평가는 한 번만 실행한다. 결과가 어떻게 나오든 이 구성과 판정으로 보고한다. 실패해도 구성을 바꿔 다시 평가하지 않는다.
