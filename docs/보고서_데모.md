## 분자 하나에 신뢰성을 붙이는 도구

담당4 · 2026년 9월 3일 · https://mist-700016601256.asia-northeast3.run.app

### 한 줄로 말하면

SMILES를 입력하면 ADMET 예측값과 함께, 같은 분자를 다르게 적어 넣었을 때 그 예측이 얼마나 흔들리는지, 그리고 이 물성에서 어느 축을 쓸 수 있는지를 보여준다.

### 왜 만들었나

연구계획서 7.3절이 산출물로 지정한 것이다. 요구가 두 가지였다.

첫째, 세 신뢰성 축을 분리해 표시하고 **단일 점수로 합산하지 않는다.** 위험도를 하나의 숫자로 뭉개면 어느 축이 문제인지 알 수 없기 때문이다.

둘째, 계획서에 목표 출력 문장이 적혀 있다.

> 예측 구간은 좁게 산출되었으나 주요 호변이성질체와 양성자화 상태에 따라 예측값이 크게 변동하므로, 입력 표기를 확인하기 전에는 이 예측을 사용하지 않는 것이 바람직하다.

이 문장을 신호에서 자동으로 만들어내는 것이 도구의 핵심이다.

### 대표 장면

살부타몰을 뇌혈관장벽 통과 예측에 넣으면 이렇게 나온다.

| | 예측 | 원본 대비 |
| --- | --- | --- |
| 원본 표기 | 0.0116 | 기준 |
| 호변이성질체 | 0.5348 | **+0.523** |
| 양성자화 | 0.3600 | +0.348 |

같은 물질을 다르게 적었을 뿐인데 통과 확률이 1.2퍼센트에서 53.5퍼센트가 된다. 세 구조를 나란히 그려 원본과 달라진 원자를 표시하므로 거의 똑같아 보이는 분자가 전혀 다른 답을 받는다는 것이 눈으로 보인다.

판정은 이렇게 나온다.

> **주의** — 표현 불안정성과 호변이성질체와 양성자화에 따라 예측값이 크게 변동한다. 입력 표기를 확인하기 전에는 이 예측을 사용하지 않는 것이 바람직하다.
> · 예측 집합이 라벨 하나로 좁게 산출되었으나 위 변동이 거기에 반영되어 있지 않다.
> · 이 등급의 분자는 시험 분자 7979개 기준으로 전체 평균의 1.29배 비율로 크게 틀렸다.

첫 줄이 계획서가 목표로 적어둔 문장 형식이다. 모델은 음성이라고 단정하는데 입력을 바꾸면 답이 흔들린다는, 이 연구가 잡으려던 바로 그 조합이다.

### 화면이 보여주는 것

**예측값과 컨포멀 구간.** 회귀는 90퍼센트 예측 구간, 분류는 예측 집합을 낸다. 집합에 라벨이 하나면 모델이 확신한 것이고 좁은 구간과 같은 의미다.

**판정 문장.** 화면의 주인공이며 등급색 띠를 둘렀다.

**세 신뢰성 축.** 표현 안정성, 입력 상태 민감성, 화학 공간 위치를 백분위로 나란히 놓는다. 합치지 않는다.

**축별 판정.** 어느 축을 썼고 쓰지 않은 축은 왜 제외했는지, 그리고 변형 예측이 어디에 흩어지는지를 점으로 보여준다.

마지막 항목이 이 도구의 고유한 부분이다. Caco-2 투과도를 고르면 양성자화 축이 제외로 표시되고 사유가 함께 나온다. 여러 출처를 통합해 측정 pH가 보존되지 않았기 때문이다. 다른 신뢰성 도구는 쓸 수 없는 축을 말하지 않는다.

### 어떻게 만들었나

파이프라인은 데이터셋 단위로 돌아가므로 분자 하나에 쓸 수 없다. 그래서 계층을 나눴다.

| 계층 | 하는 일 |
| --- | --- |
| `engine.py` | 변형 생성, 두 모델 계열 채점, 산출물 읽기 |
| `score.py` | 축별 흩어짐과 백분위, 컨포멀 구간, 판정 문장 |
| `api.py` | HTTP 한 겹 |
| `static/` | 화면 |

채점기는 정적 산출물만 읽고 파이프라인 코드에 의존하지 않는다. 그래서 배포 환경에 그대로 옮길 수 있고, 화면을 바꿔도 채점 로직을 건드리지 않는다.

물성마다 산출물 여섯 개를 미리 뽑아둔다. 보정 분할의 신호값을 정렬한 참조 분포, 능선 회귀 계수, 컨포멀 보정값, 축별 적용 조건, 적용가능도메인 계산용 학습 이웃, 재적합 검증 기록이다.

**설정 지문을 함께 적는다.** 나중에 A축 변형을 30개로 늘리면 참조 분포가 낡는데, 대조하지 않으면 데모가 틀린 백분위를 태연히 내놓는다. 지문이 맞지 않으면 실행을 거부한다.

### 판정에 근거를 붙였다

처음에는 백분위 상위 15퍼센트를 주의로 두었는데 근거가 없었다. 화면 한가운데 놓이는 문장이 임의의 숫자에 기대고 있으면 곤란하다.

시험 분자 7,979개에서 백분위 구간별 실제 미달률을 재어 경계를 다시 정했다. 미달의 정의는 오차 탐지 라벨과 같다.

| 등급 | 분자 비율 | 실제 미달률 | 전체 대비 |
| --- | --- | --- | --- |
| 안정 | 13.4퍼센트 | 0.103 | **0.48배** |
| 보통 | 54.4퍼센트 | 0.206 | 0.96배 |
| 주의 | 32.2퍼센트 | 0.277 | **1.29배** |

주의 구간은 안정 구간보다 2.69배 자주 크게 틀린다. 이 수치가 판정 아래에 근거로 붙는다.

여기서 알게 된 것이 하나 있다. **우리 신호는 위험을 지목하는 것보다 안전을 보증하는 데 더 강하다.** 하위 구간이 0.48배로 내려가는 폭이 상위 구간이 1.29배로 올라가는 폭보다 크다. 십분위로 보면 최하위가 0.43배, 최상위가 1.36배다.

### 검증

**파이프라인과 일치하는가.** 시험 분할에 이미 있는 분자 176개를 데모로 다시 채점해 저장값과 대조했다. 실패 0건이다.

| 항목 | 결과 |
| --- | --- |
| 예측값 | 파이프라인 재적합과 **정확히 일치** (평균 절대차 0.0000) |
| 적용가능도메인 | 최대 절대차 0.000049 |
| B축 흩어짐 | 정규화 차이 중앙값 0.033 |

처음 요약이 오해를 불렀다. 물성마다 단위가 달라 원값으로 합산하니 half_life_obach의 평균 절대차가 6.33으로 찍혔다. 어느 고리가 어긋났는지 갈라보니 데모는 파이프라인과 완전히 일치하고, 남은 차이는 전부 재적합과 담당2 모델 사이의 간극이었다.

**재적합이 담당2 모델을 재현하는가.** 변형 채점은 새 분자를 넣을 수 있어야 하므로 처음부터 재적합 모델을 써왔다. 그것이 담당2 모델을 얼마나 재현하는지는 잰 적이 없었다.

상관 중앙값 0.9968, 최솟값 0.9886이다. 저장본이 없는 XGBoost 대표 8종이 오히려 더 정확한데, 랜덤 포레스트의 부트스트랩 난수가 없기 때문이다. 담당2에게 모델 객체를 요청할 필요가 없었다. **물어보기 전에 재보는 편이 나은 경우였다.**

### 배포

Google Cloud Run에 올라가 있다. 최소 인스턴스가 0이라 접속이 없으면 잠들고 과금이 발생하지 않는다. 대신 한동안 쓰지 않으면 첫 접속이 30초에서 1분 걸리므로 시연 전에 한 번 열어 깨워두는 편이 좋다.

HuggingFace Spaces는 쓰지 못했다. Docker와 Gradio SDK가 유료 요금제를 요구하도록 바뀌었고, 무료로 남은 정적 Space는 서버가 없어 임의 분자를 채점할 수 없다.

브라우저에서 파이썬을 돌리는 길도 막혀 있다. RDKit이 Pyodide에 포팅되어 있지 않고, RDKit-JS는 그림과 지문까지만 노출해 호변이성질체 열거와 양성자화를 할 수 없다. **임의 입력에는 서버가 반드시 필요하다.**

배포에 네 번 실패했고 원인이 전부 로컬에서는 드러나지 않는 종류였다. 두 번은 `requirements.txt`에 존재하지 않는 판을 적어서였고, 두 번은 RDKit이 링크하는 시스템 라이브러리가 slim 이미지에 없어서였다. 후자는 하나씩 드러나는 구조라 휠의 공유 라이브러리에서 의존 목록을 전부 뽑아 한 번에 넣고서야 통과했다.

배포본에는 물성 넷을 실었다. 전체 산출물이 585MB이고 그중 하나가 247MB라 그대로는 올릴 수 없다. 고른 기준은 이야기다. bbb_martins는 호변이성질체 하나로 예측이 뒤집히고, herg는 안전성 평가에서 널리 쓰이며, lipophilicity는 컨포멀 구간이 나오는 회귀다. caco2_wang은 양성자화 축이 제외되는 사례라서 넣었다. 22종을 다 실으면 그 장면이 오히려 묻힌다.

### 갱신

팀원 작업이 반영되면 데모도 다시 만들어야 한다. `demo/deploy/refresh.sh`가 판정 보정, 산출물, 배포 묶음, 배포를 순서대로 밟는다. 배포 묶음만 다시 싸면 낡은 참조 분포가 그대로 올라가므로 순서가 중요하다.

설정 지문은 변형 생성 설정만 덮는다. 모델이 교체되거나 결합 계수가 바뀌면 지문이 그대로여서 조용히 옛 값을 계속 낸다. 그래서 물성마다 결합 계수와 참조 신호 목록, 대표 모델을 묶은 재료 지문을 따로 남기고 산출물 생성 시각을 화면에 표시한다.

변형 재생성(A-3), 새 신호 추가(B-2), 결합 규칙에 영향을 주는 변경(B-3)이 갱신 대상이다. 통계 절차 변경(B-1)은 보고 신뢰구간만 바꾸므로 데모와 무관하다.

### 한계

물성 22종 중 넷만 실려 있다. 용량 때문이며 산출물 자체는 22종 모두 있다.

첫 접속이 30초에서 1분 걸린다. 과금을 0으로 유지하는 대가다.

표현 불안정성 축은 파이프라인과 대조할 수 없다. 무작위 SMILES 생성 시드가 달라 변형 집합 자체가 다르기 때문이며 설계상 그렇다.

회귀 물성의 ChemBERTa 컨포멀은 결합 규칙에서 빠져 있다. 담당2의 척도 함수가 우리가 가진 재료와 무관해(지문 시드 표준편차와 상관 0.05) 재구성할 수 없다. 정의를 확인하면 채울 수 있으며 분류 13종은 이미 전부 쓰고 있다.
