## 사전 기록 2. 새 CYP 데이터에서의 B축 효과 재현

작성 2026-09-26. 이 문서는 새 데이터의 B축 효과를 평가하기 전에 커밋한다. 새 데이터에 대해 이미 수행한 작업은 분할, 지문 모델 학습, 변형 생성처럼 오차와 B 신호를 대조하지 않는 작업뿐이다. 새 데이터에서 B 신호와 오차의 관계는 이 문서를 커밋하기 전에 보지 않았다.

### 배경과 투명성

22종(`scores_role4_r2`)에서 B축 효과가 CYP 물성에 집중되는 것을 관찰했다. 또 같은 22종에서 여러 B 구성을 비교한 끝에 아래 구성을 골랐다(`scripts/explore_fp_only_configs.py`, `scores_role4_r2/explore_fp_only.csv`). 따라서 22종 결과는 탐색이며, 이 문서의 목적은 결과를 보지 않은 데이터에서 같은 구성이 재현되는지 한 번 확인하는 것이다.

사전 기록 1(상태 민감도 조절분석)은 기각되었다. CYP 집중의 이유는 아직 설명되지 않은 상태에서 재현 여부만 검증한다.

### 데이터

TDC ADME의 CYP1A2_Veith(12,579)와 CYP2C19_Veith(12,665). 22종의 CYP 억제 3종과 같은 실험(Veith 2009, P450-Glo)이며 TDC ADMET 벤치마크 그룹에 포함되지 않아 지금까지 쓰지 않았다.

- 분할: `scripts/prepare_new_dataset.py`. 담당1의 규칙(부모 분자 중복 제거, 골격 그룹 70/10/10/10, 고리 유무 층화, 시드 42)을 그대로 따른다.
- 허용성: CYP 억제 3종과 같은 실험이므로 같은 판정(네 축 모두 허용)을 쓴다. 축 사용 여부는 새 데이터에서 계획서 5.4절의 10% 기준으로 다시 셌다. 호변이성질체·양성자화·입체 사용, 염 표본 부족.
- 모델: 지문 RF·XGBoost 5시드, 대표 모델은 train 교차적합으로 선택(`scripts/build_role2_fingerprint_only.py`). ChemBERTa는 학습하지 않는다.
- 변형: 22종 주 결과와 같은 설정(`generate_variants.py` 현행 상수, A 10개, pH 6.4~8.4).

### 구성

모든 구성은 물성 안 백분위 신호, meta 분할에서 오차 순위로 적합한 Ridge(alpha 1.0), test 분할의 정규화 AURC로 평가한다. 22종 파이프라인과 같은 정의다.

- 기준: 적용가능도메인 이웃, 적용가능도메인 밀도, 지문 컨포멀
- 강화 기준: 기준 + 분자 크기(무거운 원자 수), 헤테로원자 수, 조건부 변형 수
- B 모양: 조건부 B 변형에 대한 지문 대표 모델 예측의 표준편차, 최대 이탈, 방향 이동, 상대 흩어짐, 라벨 반전 비율(확장 통계, `build_rich_variant_features.py`와 같은 정의)
- B: 조건부 B 지문 표준편차

1차 비교: 기준 대 기준 + B 모양
2차 비교: 강화 기준 대 강화 기준 + B 모양
참고: 기준 대 기준 + B

22종 참고값(탐색): 1차 +0.073 [+0.032, +0.115] 16/22, 2차 +0.056 [+0.027, +0.086] 17/22, 참고 +0.037.

### 판정

효과 = 기준의 정규화 AURC − 비교 구성의 정규화 AURC. 물성마다 test 분자를 골격 그룹 단위로 2,000회 복원 추출해 95% 신뢰구간을 구한다(시드 20260926, 결합 규칙은 다시 적합하지 않음).

- 재현 성공: 두 물성 모두 1차 비교의 효과가 양수이고, 적어도 한 물성에서 골격 신뢰구간이 0을 배제한다.
- 부분 재현: 두 물성 모두 효과가 양수이나 신뢰구간이 모두 0을 포함한다.
- 재현 실패: 한 물성이라도 효과가 0 이하.

2차 비교와 참고 비교는 같은 방식으로 보고하되 판정에는 쓰지 않는다.

### 약속

평가는 한 번만 실행한다. 결과가 어떻게 나오든 이 구성과 판정으로 보고한다. 재현에 실패해도 구성을 바꿔 다시 평가하지 않는다. 재현 성공 시에만 사전 기록 3(Biogen 간 미세소체 안정성)으로 넘어간다.
