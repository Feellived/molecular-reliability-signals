## 같은 분자를 다르게 적으면 모델이 답을 바꾼다

### 입력 상태 민감성을 ADMET 예측의 신뢰성 신호로 쓸 수 있는가

MIST · Molecular Input-State sensitiviTy
TOBIG's 컨퍼런스 2026 · 2026년 9월 27일

---

## 요약

ADMET 예측 모델은 평균 정확도로 평가받지만 정작 실무에서 필요한 것은 개별 예측 하나를 믿어도 되는지다. 기존 신뢰성 지표는 모두 모델 쪽에서 나온다. 학습 데이터와 얼마나 닮았는지(적용가능도메인), 모델이 스스로 얼마나 자신 없어 하는지(컨포멀)를 본다.

우리는 **입력 쪽에서 나오는 신호**를 제안한다. 같은 화합물도 컴퓨터에 넣을 때는 표기가 여럿이고 화학적 상태도 여럿이다. 호변이성질체, 양성자화 상태, 입체 표기를 바꿔 넣었을 때 예측이 흔들린다면 그 예측은 덜 믿을 만하다는 가설이다.

TDC ADMET 22종에서 검증한 결과다.

- **사전 지정한 1차 가설이 지지된다.** 기준 모형에 B축을 더하면 정규화 AURC가 0.0286 개선되고 골격 군집 부트스트랩 신뢰구간 [+0.0031, +0.0561]이 0을 배제한다.
- **효과가 CYP 물성에 몰려 있다.** CYP 6종 평균 +0.080(6종 모두 개선), 나머지 16종 평균 +0.009.
- **이 집중이 새 데이터에서 재현됐다.** 22종에 쓰이지 않은 CYP1A2·CYP2C19에서 사전 등록한 구성으로 +0.054, +0.089를 얻었고 두 물성 모두 신뢰구간이 0을 배제했다.
- **CYP 밖으로 확장되는지는 확인하지 못했다.** Biogen 데이터에서 CYP 관련 물성이 대조 물성보다 낫지 않았다.

정직한 결론은 이것이다. **입력 상태 민감성은 CYP 억제 예측에서 기존 신호에 더해 위험 선별을 개선하는 신호이며 범용 신뢰성 지표로 쓰기에는 근거가 부족하다.**

## 1. 문제

### 1.1 평균 정확도와 개별 신뢰의 간극

신약 후보 물질을 걸러낼 때 모델은 수만 개 분자에 점수를 매긴다. 이때 "이 모델의 R²가 0.7이다"는 정보로는 지금 눈앞의 분자 하나를 실험으로 검증할지 말지 정할 수 없다. 필요한 것은 **예측별 신뢰도**다.

### 1.2 기존 신호는 모두 모델 쪽에서 나온다

| 신호 | 무엇을 보나 |
| --- | --- |
| 적용가능도메인 | 이 분자가 학습 데이터와 얼마나 닮았나 |
| 컨포멀 | 모델이 내놓는 예측 구간이 얼마나 넓은가 |
| 모델 불일치 | 서로 다른 모델이 같은 분자에 다른 답을 내는가 |

세 신호 모두 **모델과 학습 데이터**를 들여다본다. 선행 연구는 이들이 서로 상당 부분 겹친다고 보고했다. QUAD(2026)는 세 신호를 하나로 합쳤을 때 가장 좋은 단일 신호보다 오히려 나빴다고 결론지었다.

### 1.3 입력 쪽에 남은 미탐색 영역

화학 데이터베이스에 같은 약이 여러 형태로 등록된다. 중성형과 이온형, 서로 다른 호변이성질체, 입체 표기가 있는 것과 없는 것이 모두 같은 약이다. 모델은 이들을 다른 입력으로 받는다.

**그 형태를 바꿨을 때 예측이 크게 달라진다면, 애초에 어느 형태를 넣었느냐에 답이 좌우된다는 뜻이다.** 이것이 우리가 제안하는 신호다.

## 2. 방법

### 2.1 두 개의 축

| 축 | 정의 | 어디서 나오나 |
| --- | --- | --- |
| **A · 표현 불안정성** | 같은 분자를 등가 SMILES로 다시 적었을 때의 예측 흔들림 | SMILES를 읽는 언어 모델에서만 |
| **B · 입력 상태 민감성** | 호변이성질체·양성자화·입체 표기를 바꿨을 때의 흔들림 | 모든 모델에서 |

A축은 선행 연구 Maxsmi(2021)가 이미 다뤘다. 그래서 **1차 가설은 B축으로 좁혔고**, A축은 2차 가설로 두었다.

### 2.2 물성마다 쓸 수 있는 변형이 다르다

logD처럼 정의에 pH가 들어간 물성에서는 양성자화 변형이 본질적이다. 반면 여러 출처를 통합해 측정 조건이 보존되지 않은 물성에서는 그 변형이 잡음이다. 담당1이 TDC 문서와 원 논문을 읽어 물성마다 축별 허용성을 판정했고 **결과를 보기 전에 확정했다.**

### 2.3 누출을 막는 순서

```
부모 분자 확정 → 중복 제거 → 골격 기준 분할 → 그 다음에 변형 생성
```

순서를 바꾸면 같은 화합물의 다른 형태가 학습과 시험에 나뉘어 들어가 결과가 무효가 된다. 변형은 원본 행의 분할을 그대로 물려받는다.

### 2.4 평가 지표

**정규화 AURC**를 쓴다. 신뢰도 순서대로 예측을 받아들이며 누적 오차를 잰다. 0이 완벽, 1이 무작위가 되도록 정규화한 값이다. 낮을수록 좋다.

계획서 6.5절에 따라 **p값이 아니라 효과 크기와 신뢰구간으로 보고한다.**

### 2.5 규모

| 항목 | 수 |
| --- | --- |
| 물성 | 22종 (회귀 9 + 분류 13) |
| 변형 | 287,819개 |
| 예측 모델 | 지문 기반 RF·XGBoost 5시드, ChemBERTa 2판 |
| 추가 검증 데이터 | CYP1A2·CYP2C19 (25,177 화합물), Biogen 4종 (10,956 측정) |

## 3. RQ1 — 이 신호는 존재하는가

### 3.1 흔들림이 큰 분자가 실제로 더 틀린다

흔들림 상위 25퍼센트 분자는 하위 25퍼센트보다 **1.25배** 더 크게 틀린다. 신호가 존재한다는 최소 조건은 만족한다.

### 3.2 학습 데이터에서 멀어질수록 B는 오히려 작아진다

> **그림 R5 · 골격 거리별 축 크기** (`09_골격거리.png`)

"B축은 결국 학습 데이터와의 거리를 재는 것 아니냐"는 반론에 대한 답이다. 골격 거리 4분위로 나눠 보면 오차는 커지는데 축 값은 **줄어든다.**

| 축 | 가까움 → 멂 |
| --- | --- |
| 통합 B (조건부) | 0.553 → 0.510 → 0.482 → **0.472** |
| 표현 불안정성 A | 0.526 → 0.508 → 0.496 → **0.487** |
| B1 양성자화 | 0.536 → 0.542 → 0.487 → **0.452** |

**거리와 반대 방향으로 움직인다.** 같은 것을 재고 있지 않다는 직접적인 증거다.

## 4. RQ2 — 기존 신호와 다른 것을 보는가

### 4.1 순위 상관이 거의 0이다

> **그림 R6 · 신호 겹침 구조** (`05_겹침구조.png`)

| B축과의 순위 상관 | 값 |
| --- | --- |
| 적용가능도메인 | **−0.09** |
| 컨포멀 | +0.11 |
| 모델 불일치 | +0.03 |

### 4.2 상위 10퍼센트 집합도 겹치지 않는다

자카드 지수로 보면 **우리 축과 기존 신호가 0.065**다. 참고로 기존 신호끼리도 0.076으로 낮다.

### 4.3 기존 신호를 통제해도 정보가 남는다

기존 신호 네 개를 통제한 뒤에도 B와 오차의 부분 상관이 **22종 중 14종에서 양수**로 남는다. CYP에서는 0.17, 그 외에서는 0.03이다.

**RQ2의 답은 명확하다. B축은 기존 신호와 거의 겹치지 않고 기존 신호가 잡지 못하는 오차 정보를 일부 담고 있다.**

## 5. RQ3 — 기존 신호에 보태는 값이 있는가

### 5.1 사전 지정한 1차 가설은 지지된다

> **그림 R1 · 제거 실험** (`R1_제거실험.png`)

| 구성 | AURC 개선 | 95퍼센트 신뢰구간 | 개선 물성 |
| --- | --- | --- | --- |
| 기준 + 모델 불일치 | +0.0717 | [+0.0156, +0.1285] | 17/22 |
| 기준 + A축 | +0.0003 | [−0.0310, +0.0273] | 14/22 |
| **기준 + B축** | **+0.0286** | **[+0.0088, +0.0533]** | 14/22 |
| 기준 + A축 + B축 | +0.0238 | [−0.0074, +0.0495] | 17/22 |
| 전체 | +0.0846 | [+0.0374, +0.1350] | 18/22 |

**B축을 더하면 신뢰구간이 0을 배제한다.** 1차 가설이 지지된다. A축 단독은 그렇지 않아 2차 가설은 지지되지 않는다.

기준 모형은 계획서가 지정한 적용가능도메인과 컨포멀이다. 모델 불일치는 계획서 기준에 포함되지 않지만 **우리보다 2.5배 강한 신호**라는 사실을 감추지 않고 함께 싣는다.

### 5.2 분석 방식을 바꿔도 결론이 유지된다

| 검증 | 결과 |
| --- | --- |
| 골격 군집 부트스트랩 (분자가 아니라 골격 단위 재표집) | [+0.0031, +0.0561] — 0 배제 |
| MAD 민감도 (표준편차 대신 중앙값 절대편차) | +0.0210, **18/22 개선** |
| 계층적 분산 분해 (계획서 4.2절 정식 정의) | +0.0249, 15/22 |
| 변형 3배 확대 (A 30개, pH 5~9, 입체중심별) | +0.0247, 13/22 |

**튀는 변형 하나가 만든 결과도 아니고 근사 정의 탓도 아니다.** 변형을 세 배로 늘려도 값이 크게 달라지지 않는다.

### 5.3 실제로 쓰면 무엇이 달라지나

> **그림 R4 · 안전·위험 20퍼센트** (`R4_실사용.png`)

1,000개 후보에서 가장 믿을 만한 20퍼센트를 골라 다음 단계로 보낸다고 하자.

| | 안전하다고 고른 20퍼센트 | 위험하다고 고른 20퍼센트 |
| --- | --- | --- |
| 기준 모형 | 평균의 0.46배 | 평균의 1.61배 |
| **기준 + B축** | **평균의 0.39배** | 평균의 1.54배 |

**믿을 만한 목록이 15퍼센트 더 깨끗해진다.** 반대로 위험한 것을 골라내는 능력은 조금 떨어진다. 이 신호는 **위험 경고보다 안전 인증에 강하다.**

## 6. 효과는 어디에 있는가

### 6.1 CYP 물성에 몰려 있다

> **그림 R2 · 물성별 효과** (`R2_물성별효과.png`)

| | AURC 개선 | 개선 물성 |
| --- | --- | --- |
| **CYP 6종** | **+0.080** | **6/6** |
| 그 외 16종 | +0.009 | 8/16 |

CYP 6종은 예외 없이 개선된다. 나머지 16종은 절반만 개선되고 평균도 작다.

### 6.2 표본 수 문제가 아니다

CYP 억제 3종은 시험 분자가 1,000개 이상이지만 **CYP 기질 3종은 66개뿐인데도 모두 개선됐다.** 반대로 CYP가 아닌 물성 중 표본이 가장 큰 넷(ames, ld50, 친유성, 용해도)은 **0/4**로 하나도 개선되지 않았다.

### 6.3 단독 성능으로 보면

| 신호 단독 (정규화 AURC, 낮을수록 좋다) | 22종 | CYP 6종 | 그 외 16종 |
| --- | --- | --- | --- |
| 컨포멀 | 0.710 | 0.724 | 0.704 |
| 모델 불일치 | 0.729 | 0.767 | 0.715 |
| 적용가능도메인 | 0.757 | 0.878 | 0.712 |
| **B축** | 0.845 | **0.711** | 0.899 |
| A축 | 0.854 | 0.772 | 0.884 |

**CYP에서는 B축 단독이 모든 신호 중 가장 낫다.** 그 외 물성에서는 0.899로 무작위에 가깝다.

## 7. 새 데이터에서의 검증

6절의 CYP 집중은 **결과를 보고 발견한 패턴**이다. 그래서 구성과 판정 기준을 문서로 고정해 커밋한 뒤, 22종에 쓰이지 않은 데이터에서 **한 번만** 평가했다.

> **그림 R3 · 사전 등록 재현과 확장** (`R3_재현확장.png`)

### 7.1 재현 — 성공

**CYP1A2·CYP2C19 억제** (Veith 2009, 우리 CYP 억제 3종과 같은 실험이나 TDC 벤치마크에 미포함)

| 물성 | 1차 비교 | 골격 신뢰구간 | 2차 비교 |
| --- | --- | --- | --- |
| CYP1A2 | **+0.054** | [+0.014, +0.097] | +0.058 |
| CYP2C19 | **+0.089** | [+0.046, +0.134] | +0.091 |

2차 비교는 **분자 크기·헤테로원자 수·변형 개수를 기준에 넣은 상태**에서 더한 값이다. "결국 분자 복잡도를 재는 것뿐"이라는 반론을 새 데이터에서 막았다.

여기서 한 가지가 더 드러났다. **흔들림의 크기만 쓰는 정의로는 CYP1A2에서 효과가 없었다(−0.007).** 최대 이탈·방향 이동·라벨 반전을 함께 쓰는 정의라야 작동한다.

### 7.2 확장 — 부분 성공

**Biogen 공개 데이터**(Fang 2023). 한 회사가 같은 화합물 3,521종을 같은 조건으로 여섯 물성을 측정했다. 물성 간 차이를 데이터 수집 방식 탓으로 돌릴 수 없는 설계다.

| 물성 | 분류 | 1차 비교 | 신뢰구간 |
| --- | --- | --- | --- |
| 사람 간 미세소체 | CYP 관련 | +0.023 | [−0.087, +0.139] |
| 쥐 간 미세소체 | CYP 관련 | +0.045 | [−0.049, +0.133] |
| MDR1-MDCK 유출 | 대조 | +0.101 | [−0.063, +0.264] |
| 용해도 pH 6.8 | 대조 | +0.022 | [−0.033, +0.083] |

네 물성 모두 양수였지만 **대조 물성이 CYP 관련 물성보다 크게 나왔고 어느 것도 신뢰구간이 0을 배제하지 못했다.**

사전 기록에 "대조에서도 같은 크기면 CYP 특이성 주장은 성립하지 않는다"고 적어뒀다. 그 경우에 해당한다. 시험 분자가 217~308개로 CYP1A2(1,255개)의 4분의 1이라 검정력이 부족했던 것으로 보이지만 **구성을 바꿔 다시 돌리지 않고 이대로 보고한다.**

## 8. 시도했으나 효과가 없었던 것

숨기지 않고 싣는다. 같은 길을 다시 걷지 않게 하기 위해서다.

| 시도 | 결과 |
| --- | --- |
| 여러 결합기 (로지스틱, 랜덤포레스트 등 7종) | 전부 실패. 결합기 복잡화는 답이 아니었다 |
| 축을 개별 변수로 분리 | 변수가 늘어 과적합, 악화 |
| 물성 통합 게이팅 | AURC는 개선되나 AUPRC 정체 |
| 축 분산을 컨포멀 척도 함수로 | 구간 폭이 3배로 폭발 |
| 변형 3배 확대 | 신호가 강해지지 않음 |
| 호변이성질체 안정성 필터 | 엄격히 거를수록 악화 (+0.037 → +0.013) |
| 상태 민감도로 CYP 집중 설명 | **사전 등록 후 기각** (ρ = −0.28, p = 0.81) |

마지막 항목을 덧붙인다. "CYP는 이온화에 민감해서 잘 되는 것"이라는 가설을 검증하려고 라벨과 구조만으로 물성별 민감도 지표를 정의해 커밋한 뒤 계산했는데, **오히려 음의 상관**이 나왔다. CYP 집중의 이유는 아직 설명되지 않았다.

## 10. 어디까지 주장할 수 있나

### 주장할 수 있는 것

- **사전 지정한 1차 가설이 지지된다.** 계획서가 정한 기준 모형 대비 B축 추가가 위험 선별을 개선하고 신뢰구간이 0을 배제한다.
- **이 신호는 기존 신호와 원천이 다르다.** 순위 상관이 거의 0이고 골격 거리와 반대로 움직이며 기존 신호를 통제해도 정보가 남는다.
- **CYP 억제 물성에서 유효하며 독립 데이터 두 종에서 재현됐다.** 구성을 결과 관찰 전에 고정했고 평가는 한 번만 했다.
- **안전 인증에 강하다.** 믿을 만하다고 고른 20퍼센트의 오류율이 기준의 0.46배에서 0.39배로 낮아진다.

### 주장할 수 없는 것

- **범용 신뢰성 지표.** CYP 밖에서는 효과를 확인하지 못했다.
- **기존 신호를 대체한다.** 모델 불일치가 우리보다 2.5배 강하다.
- **CYP 관련 물성 전반으로의 확장.** Biogen에서 확인하지 못했다.
- **CYP에서 잘 되는 이유.** 사전 등록한 설명 가설이 기각됐다.

## 11. 한계

1. **효과 크기가 작다.** 기준 대비 5퍼센트 수준이다. 다만 분야 전체가 이 수준이다. 가장 강한 기존 신호도 무작위에서 완벽까지의 30퍼센트밖에 가지 못한다.
2. **물성 22종은 효과 크기 +0.01을 가려내기에 부족하다.** CYP 밖 16종의 신뢰구간이 [−0.006, +0.028]로 넓다.
3. **언어 모델이 ChemBERTa 하나뿐이다.** A축은 원리상 문자열 모델에서만 나오므로 구조 기반 모델로는 검증할 수 없다.
4. **CYP 집중이 사후 발견이다.** 새 데이터로 재현했지만 애초에 이 패턴을 찾은 것은 결과를 본 뒤였다.
5. **측정 조건 분류에 민감하다.** 초기에 "pH 조건이 맞는 물성에서만 작동한다"는 결과를 얻었으나 담당1이 허용성 표를 개정해 물성 3종이 그룹을 옮기자 결론이 뒤집혔다. 이 결과는 주 결과에서 제외했다.
