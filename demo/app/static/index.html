같은 분자를 다르게 적어 넣었을 때 모델이 답을 바꾸는가

예시
  1. 같은 분자를 여러 형태로 다시 적는다. 등가 SMILES 표기, 호변이성질체, 양성자화 상태, 입체 표기를 바꾼 판을 만든다.
  2. 전부 모델에 넣고 답이 흔들리는지 본다. 지문 기반 모델과 SMILES 언어 모델 두 계열을 함께 쓴다.
  3. 흔들리면 그 예측은 믿기 어렵다. 흔들림 상위 25퍼센트 분자가 하위 25퍼센트보다 1.25배 더 틀린다.

물성마다 쓸 수 있는 변형이 다르다. 측정 조건에 맞지 않는 축은 쓰지 않고, 왜 제외했는지 함께 보여준다.

판정

    신뢰성 축

    세 축은 서로 다른 것을 잰다. 하나의 점수로 합치지 않는다.

    무엇이 예측을 흔들었나

    같은 물질을 다르게 적은 것뿐인데 모델의 답이 달라진다.

    축별 판정

    어느 축을 썼고, 쓰지 않은 축은 왜 제외했는지.
