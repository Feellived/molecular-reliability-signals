# 사전 기록 4: 예측 확신도를 기준선에 넣었을 때

등록한 기준선(적용가능도메인 + 컨포멀)에는 예측 확신도(|p − 0.5|)가 없었다. 이 폴더는 확신도를 기준선에 먼저 넣고 B축을 더했을 때 CYP 효과가 남는지 확인한 사후 추가 실험이다.

| 파일 | 내용 |
| --- | --- |
| `사전기록_4_확신도기준선_라이브러리의존.md` | 구성과 판정 기준 (실행 전 고정) |
| `기록_해시.txt` | 사전 기록의 SHA-256과 고정 시각(2026-11-17 12:11:34 KST) |
| `exp12.py` | 분석 코드. 한 번만 실행했다 |
| `실행시각.txt` · `재현점검.json` | 실행 시각(12:14:05)과 재현 점검 세 가지(모두 통과) |
| `결과.json` · `실험1_물성별.csv` · `결과_요약.md` | 결과 |
| `단독신호_분류13종.csv` | 분류 13종의 단독 신호 비교 (사후 탐색) |

- 사전 기록의 가설은 결과를 본 뒤에 세웠다. 고정한 것은 판정 기준이다.
- 실험 1의 사전 지정 판정은 **소멸**이다. CYP 6종의 B 추가 효과는 +0.0802에서 +0.0165 [−0.0473, +0.0639]로 줄었다.
- `exp12.py`는 실행 당시 보관본의 절대경로를 쓰던 한 줄(`ARCH`)만 저장소 상대경로로 바꿨고 논리는 그대로다. 실행하려면 `data/`를 스크립트로 재생성해야 한다.
